#Predicting Youth Electronic Cigarette Use

#Project Overview

This project was developed for the HI780 Data Mining in Healthcare course at George Mason University. 
The primary goal is to use machine learning to predict whether a youth has "ever used" electronic cigarettes 
based on various independent variables.

#Dataset

The analysis utilizes the 2022 National Youth Tobacco Survey (NYTS) Dataset.

File: nyts2022_ecig_ml_complete.csv

Focus: Identifying key predictors of e-cigarette experimentation among youth.

#Tech Stack

The following Python libraries were used to perform data cleaning, modeling, and evaluation:

  1.Pandas & NumPy: Data manipulation and preprocessing.
  
  2.Scikit-Learn: Implementing Logistic Regression, Decision Trees, and Random Forest models.
  
  3.Matplotlib: Visualizing model performance via ROC curves.
  
  4.Jupyter Notebook: Interactive development environment.

#Getting Started

To run this project locally, follow these steps:

  1.Clone the repository: https://github.com

  2.Install the required dependencies: pip install -r requirements.txt

  3.Open the notebook: jupyter notebook Panthers_Final_Project.ipynb

#Model Evaluation

The models are evaluated based on:

  1.Accuracy, Precision, Recall, and F1-Score.

  2.Area Under the ROC Curve (AUC-ROC).
